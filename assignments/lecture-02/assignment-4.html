Library Books: Filter, Update & Delete

Medium⏱ 35–40 min

A school library catalogue to practise everything from Lecture 2: filtering with comparison and logical operators, IN and BETWEEN, then changing and removing rows.

WHEREAND / OR / NOTIN / NOT INBETWEENUPDATEDELETE
DATASET

Working data

A school library keeps its catalogue in a table called LibraryBooks. Set it up first by running the two statements below in your MySQL, then complete the questions.

1. Create the table

CREATE TABLE LibraryBooks (
    BookID INT PRIMARY KEY,
    BookName VARCHAR(50),
    Category VARCHAR(30),
    Price DECIMAL(8,2),
    Copies INT,
    Publisher VARCHAR(50)
);
