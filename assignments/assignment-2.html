Working data

You are building the backend for a music-playlist app. First create a table called tracks with this specification:

  • track_id — integer, the PRIMARY KEY
  • track_name — text up to 60 characters, cannot be empty
  • artist — text up to 40 characters, cannot be empty
  • genre — text up to 20 characters, cannot be empty
  • duration_sec — integer, must be greater than 0
  • rating — a decimal with one digit after the point (like 4.5), may be left empty (NULL), but if given must be between 0 and 5

Then insert the following 10 rows into it. Keep this table — Assignment 3 continues on the same data.
