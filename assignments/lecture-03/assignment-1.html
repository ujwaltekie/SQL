DATASET

Working data

A film-ratings database. Set it up first by running these statements in your MySQL, then work through the questions.

Part 1 · Create the table

CREATE TABLE MovieRatings (
    MovieID INT PRIMARY KEY,
    MovieName VARCHAR(50),
    Genre VARCHAR(30),
    Rating DECIMAL(3,1),
    ReleaseYear INT,
    Director VARCHAR(40)
);
