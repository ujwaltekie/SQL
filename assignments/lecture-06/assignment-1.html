Inner Join: Food Delivery Orders

Hard⏱ 50–55 min

Three linked tables from a food-delivery app. Chain INNER JOINs across all of them, add conditions, and summarise the results with grouping.

INNER JOINThree-table joinConditions in ON / WHEREBETWEENGROUP BY / HAVING
DATASET

Working data

A food-delivery app stores its data in three linked tables. Orders holds two foreign keys: CustomerID points to Customers and RestaurantID points to Restaurants. Set the tables up, then answer every question using INNER JOIN.

1. Create the tables

CREATE TABLE Restaurants (
    RestaurantID INT PRIMARY KEY,
    RestaurantName VARCHAR(40),
    City VARCHAR(30),
    Cuisine VARCHAR(30)
);

CREATE TABLE Customers (
    CustomerID INT PRIMARY KEY,
    CustomerName VARCHAR(40),
    City VARCHAR(30)
);

CREATE TABLE Orders (
    OrderID INT PRIMARY KEY,
    CustomerID INT,
    RestaurantID INT,
    Amount DECIMAL(8,2),
    OrderDate DATE,
    Status VARCHAR(20),
    FOREIGN KEY (CustomerID) REFERENCES Customers(CustomerID),
    FOREIGN KEY (RestaurantID) REFERENCES Restaurants(RestaurantID)
);
