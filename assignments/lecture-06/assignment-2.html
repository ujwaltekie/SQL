Right Join: Orders & Products

Hard⏱ 45–50 min

A shop where some products sell well and some never sell. Use RIGHT JOIN to keep every product, find the ones with no orders, and see what happens to an order with no product.

RIGHT JOINIS NULLON vs WHERECOUNT with joinsGROUP BY
DATASET

Working data

A school-supplies shop keeps its catalogue in Products and its sales in Orders. Write every query with Orders as the left table and Products as the right table, using RIGHT JOIN.

1. Create the tables

CREATE TABLE Products (
    ProductID INT PRIMARY KEY,
    ProductName VARCHAR(40),
    Category VARCHAR(30),
    Price DECIMAL(8,2)
);

CREATE TABLE Orders (
    OrderID INT PRIMARY KEY,
    ProductID INT,
    Quantity INT,
    OrderDate DATE,
    CustomerName VARCHAR(40),
    FOREIGN KEY (ProductID) REFERENCES Products(ProductID)
);
