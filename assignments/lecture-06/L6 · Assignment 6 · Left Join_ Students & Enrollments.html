Left Join: Students & Enrollments

Medium⏱ 45 min

A learning platform where some students have enrolled in several courses and some in none. Use LEFT JOIN to keep every student, find the ones with no match, and count correctly.

LEFT JOINIS NULLON vs WHERECOUNT with joinsGROUP BY / HAVING
DATASET

Working data

An online learning platform stores its learners in Students and their course sign-ups in Enrollments. A student can have many enrollments, or none. Set up the tables, then answer every question using LEFT JOIN with Students as the left table.

1. Create the tables

CREATE TABLE Students (
    StudentID INT PRIMARY KEY,
    StudentName VARCHAR(40),
    City VARCHAR(30)
);

CREATE TABLE Enrollments (
    EnrollmentID INT PRIMARY KEY,
    StudentID INT,
    CourseName VARCHAR(40),
    Fee DECIMAL(8,2),
    Status VARCHAR(20),
    FOREIGN KEY (StudentID) REFERENCES Students(StudentID)
);
